# student-tool-kit
student tool kit - acollection of usefull tools for students 

## 🚀 Deployment

This project is automatically deployed to GitHub Pages using GitHub Actions.

### How it works:
1. Push to the `main` branch
2. GitHub Actions builds the project with Vite
3. The `dist` folder is deployed to GitHub Pages
4. Your site will be available at: `https://YOUR_USERNAME.github.io/student-tool-kit/`

### Manual deployment:
1. Go to your repository on GitHub
2. Click on the **Actions** tab
3. Select **Deploy to GitHub Pages** workflow
4. Click **Run workflow**

### First-time setup:
1. Go to your repository **Settings** → **Pages**
2. Under **Build and deployment** → **Source**, select **GitHub Actions**
3. Push to `main` branch or manually trigger the workflow

### Local development:
```bash
npm install
npm run dev
```

### Local build:
```bash
npm run build
```
